Read [VISION.md](VISION.md) before discussing product direction, public onboarding or architecture that
changes the product boundary. It is the canonical shared product vision; distinguish stated direction,
recommendations and implemented behavior.

This repository owns the organization profile and product vision. Keep runtime code and operational
contracts with their source repository. Shared reference documentation lives in
[tj-agents/docs](https://github.com/tj-agents/docs).
